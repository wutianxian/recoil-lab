EA 指南说明开火时水平移动准星可以降低后坐力。Torje 在原始录像中演示了横移时用鼠标跟枪。1.3.0 的相对跟枪补偿是独立的训练近似。EA 指南 · Torje 实测演示

  • src/engine/tracking.ts 根据双方相对位置计算有方向的目标角速度。
  • src/engine/recoil.ts 将同向、近准星的匹配角速度换算为额外衰减。只在击发时应用，保持每发的衰减比例。
  • src/main.ts 和 HUD 接通开关与角速度读数。查看公式口径与实现假设。
