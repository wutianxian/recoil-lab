训练靶场实现说明

  • 枪械参数、逐发增量和所有视听元素为原创训练近似。可在 武器数据 修改弹匣、RPM、伤害、换弹、开镜时间和逐发角度。角度顺序为水平向右、垂直向上。
  • 基础 FOV 是 4:3 参考横向角。窗口比例变化时保持垂直覆盖范围。先按基础 FOV 求焦距，再乘以光学倍率并换算为开镜 FOV。开镜灵敏度使用倍率系数除以光学倍率，按过渡进度混合。
  • 视角和移动以米、度、秒计算。480 Hz 固定步长独立驱动移动、开镜、假人和枪械。正常击发间隔为 60 / RPM，从上一计划击发时刻累加。
  • 使用近 60 ms 的有符号鼠标偏航变化计算净转向速度。后坐力和步伐晃动不计入触发量。横移抵消出现在真实投影中，角色的位置变化会改变目标的视角。
  • 瞬时射线在相机局部坐标系内采样圆锥散布。命中按目标深度和身体/头部轮廓判断。倍镜内的红点漂移属于视觉层，青色引导点表示经过屏幕缩放的反向鼠标路径。训练未模拟弹速、下坠或网络插值。
  • 统计中的平均 TTK 从第一发有效伤害计时，单梭击杀率按击杀的目标计。平滑激活时长以有效射击时间为分母。离散半径使用当前弹匣射线在参考平面的离质心均方根距离。
  • 1.1.0 的反向压枪曲线以所选武器的整梭基准弹道为固定参考，逐发累加相反角度。亮点使用与视角上跳相同的时间曲线沿线推进。按屏幕空间缩放，停火后保留 0.65 秒。
  • 1.2.0 使用训练用缩短换弹，范围 0.95–1.45 秒。复仇女神采用四连发及递减组间隔，赫姆洛克采用三连发，专注轻机枪采用开火后的射速爬升。四种模式均显示同一武器的基准反向曲线。
